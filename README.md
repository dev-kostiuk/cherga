# Черга

Екран блокування з графіком відключень світла: сьогодні і завтра.

Можна додати кілька місць і кілька черг: дім, робота, батьки. Усі вони збираються на один екран і в одне посилання. Акаунта немає: список лежить у цьому браузері і в самому посиланні.

## Як це оновлюється

GitHub Action кожні 30 хвилин забирає публічні графіки і, якщо години змінились, записує їх у `data/schedules.json`. Картинки в git не лежать: та сама дія збирає їх наново і викладає на GitHub Pages, тож позначка «зараз» зсувається навіть коли сам графік той самий.

На Android MacroDroid може забирати картинку кожні 30 хвилин. На iPhone Shortcuts запускається лише в заданий час, тому в інструкції на сайті кілька точок на день.

## Запуск

```bash
python3 scripts/build_places.py /шлях/settlements.csv data/places.json
npm install
npm test
npm run update
npm run build
npm run serve
```

Сайт відкриється на `http://localhost:4173`. Довідник населених пунктів зібраний з [дампу КАТОТТГ](https://katottg.net.ua/dumps/) (CC BY 4.0) і вже лежить у `data/places.json`.

Щоб сторінка і картинки з’явились в інтернеті, у репозиторії GitHub увімкніть Pages з джерела GitHub Actions.

## Звідки графік

Сторінка неофіційна. Години беруться з публічних сторінок і API операторів, без обходу захисту сайтів. Якщо джерело не відповідає, лишається попередній графік, а на екрані видно час оновлення.

Зараз підключені Київ, Київщина, Дніпро (ДТЕК і ЦЕК), Одеса, Житомир, Полтава, Рівне, Миколаїв, Харків, Черкаси, Івано-Франківщина, Запоріжжя, Кіровоградщина, Хмельниччина, Чернівці та Чернігівщина. Інші області є в пошуку: там сказано, чому годин ще немає. Село користується графіком своєї області. Черга за адресою не визначається: її номер людина обирає сама.
